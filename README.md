# speedtest

Замер скорости интернета: скрипт 10 раз подряд скачивает файл по ссылке и считает среднее время запроса, сколько всего скачалось и скорость в МБ/с.

Нужен только Python 3.6+, сторонних библиотек нет.

## Запуск

```
git clone https://github.com/IlyaStepanov1104/speedtest.git
cd speedtest
python speedtest.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Если ссылку не передать, берётся картинка с Wikimedia (~14 МБ), она же в примере выше.

## Пример вывода

```
url: https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
 1) 14.00 МБ за 2.23 с
 2) 14.00 МБ за 2.44 с
 3) 14.00 МБ за 6.41 с
 4) 14.00 МБ за 2.32 с
 5) 14.00 МБ за 2.13 с
 6) 14.00 МБ за 2.18 с
 7) 14.00 МБ за 2.26 с
 8) 14.00 МБ за 2.98 с
 9) 14.00 МБ за 3.62 с
10) 14.00 МБ за 2.40 с

среднее время запроса: 2.90 с
скачано всего: 140.00 МБ
скорость: 4.83 МБ/с (38.7 Мбит/с)
```

МБ здесь — мегабайты (1024 * 1024 байт). Время запроса считается от отправки до получения последнего байта ответа. Скорость = всё скачанное / суммарное время запросов.

Если запрос упал или ответ пришёл не целиком (меньше, чем в Content-Length), он пишется как ошибка и в итог не идёт.
